Q&A

자주 묻는 질문

인터넷 없이도 사용할 수 있나요?

AI 분석은 내 컴퓨터에서 처리됩니다. 새로운 웹 결과를 검색할 때는 인터넷 연결이 필요합니다.

Free와 Pro의 차이는 무엇인가요?

Free는 빠른 4B 모델을 사용합니다. Pro는 8B 또는 14B 모델, 검색 보관함, Markdown·CSV 내보내기와 최대 3대 기기 사용을 제공합니다.

설치할 때 보안 경고가 표시됩니다.

공식 코드 서명 전에는 Gatekeeper 또는 SmartScreen 안내가 표시될 수 있습니다. 공식 다운로드 버튼에서 받은 파일인지 확인하세요.

결제 후 라이선스는 어디에서 확인하나요?

결제 완료 화면에서 라이선스 키가 발급됩니다. OneSearch의 열쇠 아이콘을 눌러 등록하세요.

GETTING STARTED

OneSearch 사용 가이드

01

설치

운영체제에 맞는 파일을 받은 뒤 macOS는 DMG, Windows는 EXE 설치 안내를 따르세요.

02

AI 모델 준비

첫 실행 준비 창에서 자동 설치를 누르세요. Free는 4B, Pro는 8B 또는 14B를 선택할 수 있습니다.

03

검색하고 정리

검색어를 입력하면 결과가 수집되고 로컬 AI가 의미별 폴더를 만듭니다.
